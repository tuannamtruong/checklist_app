Point this device at the shared folder

Pick a folder that your cloud client already syncs — for example Dropbox\checklist or OneDrive\checklist. This app never touches the network. It writes one file; your cloud client carries it to the other device.

This browser cannot open a folder itself — Firefox and Safari have no File System Access API, by choice. Restart the local helper with the folder and it will hand it over instead: 

npm run proto -- --folder ~/Dropbox/checklist
